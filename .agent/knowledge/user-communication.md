# How to talk to the app owner

The owner is a beginner. They asked every helper to speak in plain, everyday words and never use tech terms.

This note is the shared source of truth. Cursor also keeps a matching always-on rule in `.cursor/rules/user-experience-level.mdc`.

## What they asked for

- Always assume they are new to this.
- Do not use technical terms in messages they will read.
- Put that instruction in the app notes so every helper follows it.

## How to write replies

- Short sentences. Everyday words.
- Say what changed and what they can try next.
- Use a simple comparison if an idea is hard (a lock, a mailbox, a printed poster).
- Do not dump file names, error codes, or shop talk unless they ask, and then explain each word.

## Allowed behind the scenes

Helpers may still use normal computer words in code and in notes meant for other helpers. Only the owner-facing chat must stay plain.
